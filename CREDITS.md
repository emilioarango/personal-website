# Credits

## 3D chess knight

The hero sculpture is the knight from **A Beautiful Game**, a chess set from the Khronos glTF Sample Assets.

- Source: [KhronosGroup/glTF-Sample-Assets — ABeautifulGame](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ABeautifulGame)
- Original model: Moeen Sayed and Mujtaba Sayed, for a SideFX Karma tutorial; re-released by the Academy Software Foundation (ASWF). glTF conversion by Ed Mackey, from a GLB by Chris Rydalch and Jonathan Stone.
- License: © 2020, ASWF. [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode). Attribution **required**; a credit line is shown in the site footer.
- Changes made: extracted the single knight mesh (`Knight_B1`); removed all materials, textures and UVs; geometry and normals only. A polished black material, lighting and edge contours are applied in-engine.
- Local asset: `public/models/staunton-knight.glb`

## Fallback illustration

`public/models/knight-fallback.svg` is an original Staunton-inspired silhouette drawn for this site as a non-WebGL fallback.
